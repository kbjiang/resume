\section*{Selected Projects \& Research}

\textbf{Work Projects}

\heading{Specification-to-Calibration: Synthetic Supervision for LLM Judges}{2026}
\begin{itemize}
\item Developed a method for automating LLM judge calibration: compiled natural-language specifications into coverage-controlled positive/negative examples, using targeted behavioral contrasts to revise rubrics while holding the judge model fixed.
\item Improved position-debiased accuracy by 3.58 $\pm$ 0.58 pp on LLMBar; feedback-conditioned and GEPA-based calibration also improved balanced accuracy on BigCodeBench.
\end{itemize}

\heading{Period-Closing Skill --- Stateful, Multi-Turn Agent Evaluation}{2026}
\begin{itemize}
\item Designed 30+ reusable scenario templates covering diverse failure modes for an LLM agent that automates period-closing workflows involving due dates, calendars, worker assignment, and task dependencies; reviewed cases with the PM to validate representative scenarios.
\item Parameterized scenarios across variables such as company names, task titles, worker names, dates, schedules, and dependencies to create diverse concrete test instances without manually designing every case.
\item Built realistic multi-turn test environments with pre-existing state, calendar constraints, dependencies, and workers with similar names; fed simulated user responses back into the agent to test multi-turn behavior.
\item Separated execution-trace quality from final task success and added seeding, trace, and task verification across repeated runs; evaluated TSR, tool-call accuracy, latency, token cost, and consistency.
\end{itemize}

\heading{Account Reconciliation Agent --- Synthetic Benchmark \& Adaptive Preference Monitoring}{2026}
\begin{itemize}
\item Built an evaluation framework for an LLM agent resolving 400+ reconciliation exceptions between ledger and subledger using synthetic accounting workflows with ground-truth resolutions and tool-use paths.
\item Identified an unrealistic uniform distribution of matching cases, validated the expected distribution with the PM and statistical analysis, and recalibrated synthetic data generation; used the resulting benchmark as a fixed offline regression set.
\item Measured task success, tool-call accuracy/order/count, latency, and run-to-run consistency across repeated evaluations.
\item Designed an adaptive preference-monitoring POC using synthetic data with shifting user-preference distributions: trained a tree-based model on a previous window of exception features and user-selected actions, evaluated it on the current window, and triggered retraining when accuracy fell below a PM-approved 90\% threshold.
\end{itemize}

\heading{VLM Fine-Tuning --- Taxonomy Generalization \& Shortcut-Learning Diagnostic}{2025}
\begin{itemize}
\item Designed a hierarchical taxonomy spanning hundreds of fashion-item classes and aligned it with GPT-4o's understanding of retail products; generated $\sim$1M synthetic training examples and fine-tuned an open-source VLM with LoRA, SFT, and DPO.
\item Designed a controlled diagnostic to investigate what the model learned: after updating class names such as ``sneaker'' to ``trainer,'' the fine-tuned model failed to adopt the changes while the base model adapted, exposing taxonomy memorization.
\item Achieved $\sim$90\% accuracy against GPT-4o ground truths; used the diagnostic to motivate separating domain adaptation from taxonomy alignment through distinct training strategies.
\end{itemize}

\heading{Multimodal RAG --- Financial Insights Copilot}{2024}
\begin{itemize}

\item Identified table-parsing issues in complicated financial documents and explored normalization strategies for downstream processing; systematically evaluated BM25 configurations and reranking models, improving offline retrieval by $\sim$20\%.
\item Explored separate text/table/image indices, ranking fusion, CLIP/SigLIP cross-modal matching, LlamaIndex query decomposition, and knowledge-graph/tree-based approaches including RAPTOR, KPG, and GraphRAG.
\item Fine-tuned a Phi-3 Vision model on public chart datasets for visual question answering.
\end{itemize}
